# algo/ — движок и стратегии

Python-пакет песочницы; импортируется как `algo.*`.

- `data.py` — загрузка баров, кэш (`.cache/`), симлинк `data/`.
- `engine.py` — исполнение сделок: сигнал по close → вход по open следующего бара.
- `iss.py` — добор данных с MOEX ISS.
- `results.py` — запись прогонов в `results/runs.csv`.
- `strategies/` — реализации систем (Простушка, Универсалка, Самурай и др.).
- `configs.py`, `live.py`, `portfolio.py`, `author.py` — конфигурации,
  бумажный контур, портфель, восстановление правил автора.

Правила модели исполнения — в `../AGENTS.md` и `../docs/decisions.md`.
