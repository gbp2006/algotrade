# scripts/ — прогоны и утилиты

Нумерованные скрипты, запуск через `./run.sh <команда>` или напрямую
`./.venv/bin/python scripts/<файл>.py`.

- `01_data_check.py` — качество данных.
- `09…12` — базовые прогоны стратегий (Si, универсалка, самурай).
- `10_append_iss.py` — добор свежих баров с MOEX ISS (пишет в `cache/iss`).
- `15_sweep_full.py` — сетка параметров.
- `20…32` — сигнал, бумажный контур, отчёты, живой paper-live.
- `41…46` — веб-ассеты, восстановление правил автора, ноги портфеля.
- `94_context_cleanup.py` — компакт крупных сессий, проверка/починка индекса, учёт токенов.
- `96_mcp_profile.py` — переключение MCP-профилей `work|research|broker`.

Каждый прогон обязан оставить строку в `results/runs.csv` и печатать не
больше 6 строк сводки; подробности — в `reports/`.
