Счета и брокеры

Экспозиция: 2.0 — правило Силаева (200% номинала), 1.0 — половинный сайз, 0.25 — один контракт на 50 тыс. ₽. Лот = equity × экспозиция / (цена × множитель).
Ключ счёта вставляется сюда один раз: он сохранится в auth.json с правами 600, а в карточке счёта останется только имя. Робот берёт ключ из выбранного счёта.
Избранное — инструменты для торговли; показываются первыми. Ликвидные — топ по обороту/открытому интересу с MOEX ISS.

Новый робот

ID создаётся автоматически из имени; имя попадёт в журнал как примечание.
Переключатели: включено = true, выключено = false. Подсказка — при наведении.

Перевод в бой

Инстанс получит mode=live и статус active. Реальная заявка не уйдёт: нужны ещё `--arm` и `FINAM_ALLOW_TRADING=1`.

Параметры робота

Активный робот при сохранении уйдёт на паузу; создаётся новая версия параметров.

Переключатели: включено = true, выключено = false; `*` — отличается от дефолта.
