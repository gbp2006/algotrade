# Архив

## `research/` — исследовательские прогоны

Скрипты 48–91, OsEngine-пакет и одноразовые утилиты (42 файла), которые
участвовали в поиске стратегий, но **не входят в рабочий контур**: панель,
бумажный раннер, тень, бой, watchdog и планировщик их не вызывают.

Зачем оставлены: по ним воспроизводятся отчёты в `reports/` (30 систем,
390 OOS-окон). Удалять нельзя без потери результатов; обратно в `scripts/`
возвращать только по явному решению и с ADR.

Как запускать из корня репозитория ( пути внутри уже перенастроены ):

```bash
./.venv/bin/python archive/research/79_rigorous_validation.py
```

Скрипты читают данные из `data/` через `algo.data`, пишут сводки в `reports/`
и строки в `results/runs.csv`. Деплой-whitelist (`scripts/*.py`) архив не
включает — на WSL эти файлы не выкладываются.
