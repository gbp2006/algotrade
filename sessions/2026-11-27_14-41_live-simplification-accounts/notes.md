### 19:55–20:08 — баг правки счёта
- Пользователь не смог отредактировать счёт: `{"detail":"нет счёта КлФ-2115210"}`.
  Причина: фронтенд клал новый ID и в URL `PATCH /api/accounts/{id}`, бэкенд
  искал счёт уже по новому имени.
- Исправлено: в URL уходит исходный ID (`editOriginalId`), новый — только
  в `new_id`; ключ и журналы переезжают бэкендом. Поле ID сделано заметным
  (жирная подпись, плейсхолдер, автофокус).
- Через панель применена правка пользователя: счёт `Дневной канал (cb-day)`
  → ID `2115210`, ключ `acc:2115210`, статус ok, баланс 20 000 ₽.
- В `check-all.mjs` добавлена регрессия с перехватом PATCH: проверяет, что старый
  ID остался в URL, а новый ушёл в `new_id`; реальные данные не меняются.
- Коммиты `6b2e3c8`, `b31d1e6`, `6fc6dda`, `7f8eda4` запушены и выложены.
