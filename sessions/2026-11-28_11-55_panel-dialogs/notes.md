### 11:58 — Найденная проблема: сырой JSON в интерфейсе
При обзоре `webui/src` нашлись три вывода `JSON.stringify` пользователю:
- `Robots.tsx:577` — сводка справочника инструментов (`total/enriched/last_refresh/last_error`)
  показывалась как `{…}`;
- `Robots.tsx:173` — результат ребаланса/закрытия фонда (`setNotice(JSON.stringify(data))`);
- `Robots.tsx:210` — результат «★ Избранное / Параметры / Обновить каталог / Топ ликвидных»
  (`slice(0, 240)` от JSON).
Это прямое нарушение принципа human-readable UI из `reports/research/human-readable-ui.md`
и «антипаттерна» из `reports/research/gui-ux-patterns.md` (сырой JSON как главный текст).
Решено: сделать **одну** завершённую правку — человекочитаемые формулировки ответов,
не затрагивая API и модель исполнения.
