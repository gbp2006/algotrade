## 17:55 — Контекст проекта

## 18:10 — Результат

Написан отчёт `reports/koval-zaytsev-strategy-search.md`: 13 кандидатов с ID
KZ-01…KZ-13, дословные правила топ-идей, оценка применимости к нашим данным,
две честные интерпретации «пробоя дня» под нашу модель исполнения, рекомендация.

Главное: приоритет KZ-02 («пробой дня» + тренд/сквиз/сезонность), затем KZ-01/KZ-03
как контроля; KZ-04/KZ-05 — новые для нас внутридневные правила на Si/RTS;
арбитраж (KZ-12) нереализуем без второй площадки; KZ-07 невоспроизводим из-за
отсутствия ночных баров. Ничего не добавлялось в `CONFIGS`, код не менялся.

Открытые вопросы:
1. Если пользователь захочет прототип — уточнить интерпретацию `data2`
   (дневной стоп next day vs внутридневной close→next open), прогнать обе.
2. Для KZ-05 сверить с текущим `p-friday`, чтобы не удвоить пятничную экспозицию.
3. KZ-13 («система 5 дней») требует расшифровки видео или Excel автора.
