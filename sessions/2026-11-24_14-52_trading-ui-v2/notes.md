### 14:52 — Изучение чужих интерфейсов (web)
- Kraken Pro: независимые модули (chart, book, order form, balances) + нижняя
  лента вкладок (balances/positions/open orders/conditional/portfolio/closed
  orders/trades); пользователь сам собирает рабочее место.
- TradingView: фиксированный график в центре, инструменты по краям.
- Binance: плотность пяти живых зон без потери читаемости; OKX: покупка и
  продажа рядом, без переключателя — снижение ошибок ввода.
- Общие требования 2026: WebSocket/реaltime, визуализация портфеля на каждом
  тике, валидация заявок, адаптив, тёмная тема.
- OsEngine: четыре-program разделение (OsData / OsTester / OsOptimizer /
  OsTrader=Bot station) и MCP API со 100+ инструментами/SSE/API-ключом.
  Уроки для нас: разделить «данные/тест/бой/журнал», дать API на каждое действие
  и не смешивать настройку стратегии с управлением running-инстансом.
