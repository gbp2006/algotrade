## 00:56 — Замер потребления

Источник — БД профиля `algo`: `/home/zt/.local/share/opencode-algo/opencode/opencode.db`,
таблица `session_message`, поле `data.tokens` ответов ассистента.

Итог за 18–24.11 (сумма по всем сессиям):
- cache read ~926 251 444 токенов; свежий input 17 623 186; output 1 479 504;
  reasoning 1 460 372; 5 531 ответ.
- По дням (все токены): 19.11 — 204 млн, 20.11 — 138 млн, 21.11 — 87 млн,
  23.11 — 438 млн, 24.11 — 53 млн.

## 01:03 — Автоматизация (продолжение по просьбе пользователя)

Пользователь попросил автоматизировать чистку и запускать compaction чаще.

Разобраны возможности OpenCode v2.4.1: `compaction.{auto,background,keep.tokens,buffer}`,
`tool_output.{max_lines,max_bytes}` в конфиге и ручной вызов
`opencode api post /api/session/<id>/compact --data '{}'` (проверен на несуществующей
сессии — эндпоинт отвечает 404 SessionNotFound, значит путь верный).

Сделано:
- `opencode.jsonc`: `buffer=35%` (авто-compact примерно при 65% окна вместо 85%),
  `keep.tokens=12000`, `background=true`, `tool_output` 200 строк / 16 КБ.
  JSONC проверен парсером — синтаксис корректен.
- `scripts/94_context_cleanup.py`: принудительный `/compact` для сессий проекта с
  input ≥40k или cache-read ≥300k, обновлявшихся за последние 12 ч, не чаще 1 раза
  в 3 ч (состояние в `results/context_cleanup_state.json`); плюс пересборка индекса,
  удаление `__pycache__` и старых `INDEX.md.bak-*`, сигнал при росте
  PROGRESS/decisions/INDEX выше порогов. Содержательно файлы не переписывает.
- automation `aut_20a6df8b5001s3OEuCfD0cvxpx` — cron `0 */4 * * *` (МСК), shell-aktion
  запускает скрипт; первый запуск 24.11 04:00 МСК. Без модели, точек не тратит.
- Проверено: `python3 scripts/94_context_cleanup.py --files-only` → индекс OK,
  удалено 6 производных каталогов, урезка не нужна. Добавлены 2 ADR 24.11,
  обновлены `AGENTS.md` и `PROGRESS.md`.

Ограничение: `/api/config` сервиса не показывает проектный конфиг (только глобальный),
поэтому новые пороги вступают в силу для новых сессий; текущая сессия может
продолжаться со старыми настройками до рестарта сервиса.
