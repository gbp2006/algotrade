# sessions/ — журнал работы

Одна папка на сессию: `YYYY-MM-DD_HH-MM_краткое-описание`, внутри `notes.md`.

- Пишем по ходу: время, задача, решения и причины, изменённые файлы, ошибки,
  открытые вопросы.
- Закрытие темы — запись `### <время> — Конец: <тема>` + статус
  (**решено / отложено / отклонено**); `INDEX.md` обновится сам.
- Перенесённые из хаба сессии: silayev-robot-research, author-strategy-reverse,
  prostushka-multi-futures, paper-first-run, o-s-a-lectures-sorting.
