# tests/ — юнит-тесты

`test_engine.py` — проверки исполнения сделок, издержек, шагов контрактов и
расчёта PnL. Запуск: `./run.sh test` (или `./.venv/bin/python tests/test_engine.py`).

Тесты не читают `data/` целиком и не пишут в `results/`; для новых правил
модели исполнения сначала тест, потом код.
