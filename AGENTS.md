# AGENTS.md — песочница алготрейдинга

Правила для агентов. Цель: минимум токенов, максимум повторяемости.

## Что читать в первую очередь

1. `PROGRESS.md` — состояние проекта, последние результаты, открытые вопросы (~2 КБ).
2. `docs/decisions.md` — принятые решения и почему (одна строка на решение).
3. `docs/strategies/*.md` — канонические описания систем.
4. Код — только тот файл, который правишь.

**Никогда** не читать файлы из `data/` (гигабайты) и не выводить в чат длинные таблицы.
Скрипты обязаны печатать не больше 6 строк сводки; подробности — в `reports/`.

## Структура

```
algo/            движок и стратегии (data.py, engine.py, iss.py, strategies/)
scripts/         запускаемые скрипты: 01_… 02_… по порядку
data/            симлинк на /mnt/DiskD/MOEX/Исторические данные (не коммитить)
results/         runs.csv — журнал прогонов (машиночитаемый)
reports/         отчёты для человека (*.md, эквити *.csv)
docs/            решения и спецификации систем
```

## Обязательные правила

- Новый прогон → строка в `results/runs.csv` через `algo.results.record()`.
- Вывод в консоль: `name, сделок, net, PF, DD` — одна строка на вариант.
- Большие выгрузки — в `reports/`, а в чат только путь.
- Данные не копировать: `data/` — симлинк, чтение через `algo.data.load_txt`.
- Тяжёлые данные кэшировать: `algo.data.load_cached()` (pickle в `.cache/`).
- Меняешь модель исполнения или издержек — сначала обнови `docs/decisions.md`.

## Модель исполнения (не менять молча)

- сигнал по `close` бара → сделка по `open` следующего бара;
- комиссия 0.01% за сторону, проскальзывание 1 тик;
- CNY: шаг 0.001, множитель 1000 ₽; Si: шаг 1.0, множитель 1 ₽;
- решения по субботам/воскресеньям отключаются (`skip_weekend=True`).
