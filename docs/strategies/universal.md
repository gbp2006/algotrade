# Универсалка (разделы 2.1–2.4 методички)

**Валютный режим.** Репер = цена 10:05 (можно среднее за N минут).
**Вход:** первый бар >= 13:30.
- цена >= репер * 1.004 -> лонг
- цена <= репер * 0.998 -> шорт
- иначе вне игры
**Выход:** 10:20 следующего дня (MorningExit) либо следующее решение (Daily).
**Пятница:** шорт запрещён (в наших тестах этот запрет ухудшает результат).
**Без MA, без стопов.**
