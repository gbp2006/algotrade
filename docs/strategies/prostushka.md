# Простушка (Примечание №6, 10.2024)

**Инструмент:** ближайший фьючерс Si/CNY. **ТФ:** M5. **Индикатор:** SMA-40 по close.
**Решения:** одно в сутки, первый бар >= 13:50 (закрытие бара).
**Сигнал:** close > MA -> лонг, close < MA -> шорт, иначе вне игры.
**Фильтр:** лонг отменяется, если за 3 бара было закрытие ниже своей MA; для шорта выключен.
**Пятница:** шорт запрещён.
**Удержание:** до следующего решения (24/48/72 ч), переворот при смене знака.
**Нет:** стопов, профитов, пирамидинга.
