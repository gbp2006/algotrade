# Самурай (Хитрушка-2, INI v1.6)

**ТФ:** M1. **Пул секций**, каждая — свои 3 SMA и рублёвые offset'ы.
**Вход (лонг):** MA_mid > MA_slow и close <= MA_fast − offset_in, в окне 10:30–18:49.
**Выход (лонг):** close >= MA_fast + offset_out (offset_out отрицательный).
**Шорт:** зеркально.
**Секции:** 40/500/1800 (0.005/−0.003), 20/500/1800, 10/500/1800,
30/500/1200, 20/400/1200, 10/400/1200.
**Опции (по умолчанию Off):** пятничное снижение сайза, ATR-фильтр, автороллинг.

## Авторская вариация (20.11.2026)

`algo/strategies/samurai.py:targets_author()` — строго по `20.08.19 Описание Хитрушка.docx`:
SMA только внутри `TIME_MA` 10:00–18:45, вход в 10:02–18:45, выход по подвижной `MA_FAST`,
пятничный принудительный выход. Прогон в `reports/samurai-author-backtest.md`: PF 0.02–0.48
при наших издержках; без издержек PF 1.00–1.03, то есть собственного края у сигнала нет.
Прежний `targets()` оставлен для совместимости с текущими прогонами.

Расширенное исследование (`reports/samurai-research.md`): 12 инструментов × 2 шаблона,
решётка оффсетов и OOS. Узкие оффсеты убыточны везде; широкие (CNY ×30–60, BR ×3–6)
дают PF 1.05–1.69 на 2023–25, но на CNY это 4–49 сделок и 2026 OOS — всего 1 сделка,
а по BR нет данных 2026. Устойчивость не доказана.
