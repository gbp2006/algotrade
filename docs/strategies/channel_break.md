# Пробой временного канала (OsEngine _TimeChannelBreak)

**Статус:** исследована, в бумажный тест не включена (21.11.2026).
Подробности и все цифры — `reports/channel-break-research.md`.

## Правила

OsEngine-робот И. Коваль-Зайцева на M1. Авторские параметры: StartTime=0100,
SwitchTime=1500, SL=3300 пунктов (RI), объём 1. HH/LL — экстремумы «ночной»
сессии; `dir` = сравнение закрытий на StartTime двух соседних дней. От SwitchTime
до StartTime следующего дня: `close > HH` и `dir=+1` → лонг, `close < LL` и
`dir=-1` → шорт (шорт есть только в `TCBreakClaudeV3.cs`). Выход по StartTime,
стоп V3 подтягивается к LL/HH.

## Порт

`algo/strategies/channel_break.py`, функция `targets()`:

- `channel_mode='night'` — канал ТЗ (switch предыдущего дня → start),
  `'day'` — канал как в C# `LaunchCalc` (start → switch);
- `boundary_mode='exact'` — требует бар ровно с меткой start (как OsEngine),
  `'first_bar'` — подставляет первую свечу дня;
- `sl` — абсолютный стоп в пунктах цены, `None` — только выход по времени;
- интрабарный stop-order заменён на выход по open следующего бара, если
  low/high бара задели уровень стопа (консервативно).

Исполнение — общее для песочницы: сигнал по close, сделка по open следующего
бара, 0.01% за сторону + 1 тик, `skip_weekend=True`.

## Почему не включена

1. В архивах CNY/Si/RTS нет ни одного бара 01:00 (часы 06/07–23), поэтому
   буквальная конфигурация невоспроизводима: при `boundary_mode='exact'` сделок 0.
2. Оба прокси (23:40 или 01:00 с утренней границей) меняют идею стратегии;
   расхождение ТЗ и C# в определении канала добавляет модельный риск.
3. Train 2023–25 прибылен, но OOS 2026: CNY +122 ₽ (PF 1.06), Si −2108 ₽
   (PF 0.88); альтернативные прокси на том же OOS дают PF 1.03–1.74 — разброс
   между близкими моделями больше эффекта.
4. RTS 2026 выглядит хорошо (PF 1.56), но это короткое неполное окно из ISS
   без back-adjustment и без train-проверки.

Возврат к теме возможен только с настоящими round-the-clock барами (где есть
метки после полуночи) и отдельной моделью интрабарного стопа.
