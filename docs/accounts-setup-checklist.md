# Чек-лист завода 17 реальных счетов (27.11.2026)

Рабочая инструкция для ручного завода счетов и роботов через панель
`http://192.168.0.230/`. Реальные заявки отправляются только после твоего
решения; этот документ ничего не запускает.

## 1. Что понадобится

- По одному реальному счёту Финама на каждого робота-стратегию.
- Свой API-ключ на каждый счёт. В панели можно вставить полное имя
  `КлФ-2115210` — сохранится только `2115210`, а подпись останется исходной.
- На каждом счёте: **один робот-стратегия + один `money_market`** для парковки
  свободного кэша. Фонд не меняет equity робота и не участвует в сигнале.
- `FINAM_ALLOW_TRADING`, `--arm` и ARM-тумблеры больше не нужны. Управление —
  **СТАРТ / СТОП / ЗАКРЫТЬ ВСЁ**, аварийный тормоз — STOP_REAL.

## 3. Порядок действий по каждому счёту

1. **«Счета и брокеры» → «Добавить счёт».** ID — реальный номер счёта
   брокера, название — как удобно, режим `LIVE`, поле капитала скрыто.
   API-ключ вставляется сразу; он уйдёт в `auth.json` на сервере.
2. Нажать **«Баланс»** в строке счёта. Проверить, что пришли деньги и equity
   совпадает с внесённым депозитом. Если ключ неверный — ошибка покажется
   прямо в панели.
3. **«Роботы и алгоритмы» → «Настроить»** у нужного робота:
   `Режим = LIVE`, `Счёт = только что созданный`, `Режим цены = marketable`,
   экспозиция — из таблицы выше. ATR (`risk_vol`) по умолчанию выключен.
4. Создать или настроить второго робота **«Денежный рынок»** (`money_market`)
   на этом же счёте: `FMMM@MISX`, режим `TwiceADay`, `min_balance=5000`.
   Лимиты фонда задаются в его карточке, а не в настройках счёта.
5. Нажать **«Старт · торговать»** у стратегии и у фонда. Убедиться, что в
   `/api/scheduler/jobs` появилось включённое задание `inst:<id>:schedule` с
   командой `./run.sh live-run`.
6. После первого торгового дня сверить: журнал решений робота (вкладка
   «Дневник изменений»), `/api/health`, позиции и заявки брокера.

## 4. Контрольные точки

- Виртуальный счёт (`TEST`) не может дать реальную заявку.
- Если нужно срочно выйти — кнопка **«Закрыть всё»** закрывает позиции на
  всех счетах LIVE, STOP ей не мешает, фонд не трогается.
- STOP_REAL ставится только по явному решению и блокирует новые заявки.
- Смена ID счёта в карточке переносит роботов, ключ и журналы операций.

## 5. Что делать НЕ надо

- Не правь `paper.csv` вручную: это бумажный журнал, в боевом контуре он не
  участвует.
- Не включай ATR «для проверки» — он по умолчанию выключен и включается только
  явным `risk_vol: true` в карточке робота.
- Не запускай реальный прогон «просто посмотреть» — для этого есть кнопка
  «Проверить бой (dry-run)».
