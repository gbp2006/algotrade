Заодно исправлен `multiplier=1.0` для заявки закрытия фонда (раньше брался множитель CNY из DEFAULT и номинал завышался в 1000 раз). Причина: первый же ребаланс 26.11 был rejection `количество 3043 выше лимита 100` при `dry_run`.
