# docs/ — решения и спецификации

- `decisions.md` — ADR: одна строка на решение с датой и причиной.
- `how-to.md` — полный порядок работы с песочницей.
- `strategies/` — канонические описания торговых систем.
- `sources/` — разборы внешних источников (TG-дайджесты, лекции).

Меняешь модель исполнения, издержки или правило — сначала строка в
`decisions.md`, потом код.
