# Контракты 2027 для ролла Z6→H7 (23.11.2026)

Подготовлены данные ближайших квартальных контрактов, чтобы в декабре 2026
бумажный контур и бэктест видели одну и ту же ногу.

## Что скачано

Источник: MOEX ISS через `scripts/54b_download_iss_2027.py` (общий загрузчик
`scripts/_download_iss_common.py`). Окно 2026-11-01…2027-06-30, M1 агрегирован
в M5 (ISS не отдаёт 5-минутные свечи напрямую). Файлы лежат в `cache/iss/`,
в git не попадают — это производные данные.

| Группа | Контракты | Баров M5 |
|---|---|---:|
| RTS | RIH7, RIM7 | 1 502 |
| GOLD | GDH7, GDM7 | 3 974 |
| BR | BRH7, BRM7 | 2 306 |
| Si | SiH7, SiM7 | 4 488 |
| **Всего** | 8 контрактов | **12 270** |

## Зачем

- `instruments.active_contracts()` уже видит H7/M7 через LASTTRADEDATE с ISS.
- `rollover.front_on()` сравнивает дневные объёмы контрактов; VOL-перекладка
  включена в юнитах WSL `ALGO_VOL_ROLLOVER=1`.
- Проверка на 23.11: RIZ6 ≈58 425 против RIH7 ≈531 — фронт остаётся Z6,
  преждевременного ролла нет.
- Теперь же есть и исторические бары H7, чтобы после перехода ликвидности
  можно было сравнить решение с бэктестом на одном окне дат.

## Ограничения

- M7/U7/Z7 при необходимости докачиваются тем же скриптом (сейчас только H7/M7).
- Для вечного CNYRUBF данные 2027 не нужны — ролла нет.
- Файлы квартальных контрактов не back-adjusted: на стыке контрактов цена «прыгает». Для
  честного сравнения версий параметров используется одна и та же серия.
