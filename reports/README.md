# reports/ — отчёты для человека

Markdown-отчёты и csv-выгрузки по конкретным исследованиям: сравнение
конфигураций, эквити, корреляции, проверки автора.

- Один отчёт = одна тема; в чат выводится только путь и ≤ 6 строк сводки.
- `TEMPLATE.md` — структура нового отчёта.
- Машиночитаемый журнал прогонов лежит отдельно: `results/runs.csv`.
