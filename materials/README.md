# materials/ — материалы автора и источники

Тяжёлые исходники, не для индекса и не для git:

- `comon/ST mini/` — отчёты Finam по счёту-последователю (CSV), основа
  восстановления правил автора (`algo/author.py`).
- `tg/` — выгрузки Telegram (ChatExport) и разборы.
- `tg_messages.txt`, `tg_relevant.txt` — выборки сообщений для дайджеста.
- `qq.mp4` — запись/материал для разбора (не коммитить).
- `MOEX-КАРТА.md` — **карта архива** (что где, статус стратегий, ссылки на
  отчёты и роботов). Лежит здесь, а не внутри `moex/`, чтобы попадать в git
  и в индекс памяти.
- `moex/` — весь архив `/mnt/DiskD/MOEX/` (~43 ГБ), **физически перемещён**
  сюда rename'ом и рассортирован на 5 смысловых разделов. В `.gitignore`,
  не коммитить. Поиск — `./infra/db/moex_catalog.py`, описание — `MOEX-КАРТА.md`
  и `docs/sources/moex-archive.md`.

Изменять содержимое только при обновлении источника; выводы — в `docs/sources/`.
